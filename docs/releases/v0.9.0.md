# BoundEvo v0.9.0 — Complete 29-Function CEC2017 10k-FE Study

This release adds a full 29-function CEC2017 validation at 30 dimensions,
recorded at 10,000 objective evaluations per trial. Results are *measured*
by GitHub Actions; README plots are generated directly from committed CSVs.

## Actual experiments

- All 29 official CEC2017 functions (F1, F3–F30; F2 omitted).
- ABC, EDBF, and RE, three paired seeds each; **261 real optimization trials**.
- **10,000 evaluations** per trial, population N=100, M=15, K=5, L=1.
- Four concurrent computation shards; each saves completed trials, convergence
  states, and source manifests.
- **5,481 actual convergence checkpoints** archived and checked.
- Fixed independent reference-derived CEC2017 implementation at
  `tilleyd/cec2017-py` commit
  `424a9fa2757914c3e4cfdd8f59a268b1aeb3197f`.

### Observed average-error leaders

| Method | Functions led | Average rank (lower better) |
|---|---:|---:|
| ABC | **27/29** | **1.069** |
| EDBF | 1/29 (F22) | 2.897 |
| RE | 1/29 (F16) | 2.034 |

Friedman across 29 function-level matched blocks:
**p ≈ 2.97 × 10⁻¹¹**.

Pairwise Wilcoxon tests on log10 function-level mean error
(ABC against EDBF and RE; Holm adjusted together):
**p ≈ 1.49 × 10⁻⁸** for each comparison.

These tests are exploratory, do not establish per-function statistical
superiority, and do not make 29 functions independent random samples of all
real-world optimization problems. **Only three seeds per function** are used.

## Ranking instability as evaluation budgets increase

Comparing the same 29 functions and 3-seed schedule at 1,200 versus 10,000
function evaluations found **three changes** in the leading method:

- F16: ABC → RE
- F20: RE → ABC
- F22: RE → EDBF

Earlier *ten-seed*, four-function 10k-FE experiments had a different F22 mean
leader (ABC). That underscores the uncertainty of three-seed mean rankings.

## Scientific and engineering limits

These experiments use the independent Python port rather than the
organizers' original official C binary, and 10,000 evaluations rather
than the source paper's 100,000. The 3-seed design is a broad exploratory
screen, not a publication-grade demonstration for each function. Historical
cohorts with different budgets, repetition counts or benchmark backends
must remain separate.

Automated tests cover Python 3.10/3.11/3.12, benchmark smoke tests,
experiment pipeline, package builds, data-integrity checks, and the
README/figure regeneration workflow.
