# BoundEvo v0.10.0 — Independent 20-Seed Robustness Validation

Version 0.10 tests whether F16 and F22 conclusions from earlier
small-seed CEC2017 benchmarks persist when evaluated on **new,
previously unused random seeds**.

## 120 completed real optimization trials

- CEC2017 **F16 and F22**, 30 dimensions, **10,000 function evaluations** per run.
- ABC, EDBF and RE, **20 new paired seeds** for each function and method;
  total **2 × 3 × 20 = 120 finished trials**.
- Every method starts from a matched initial population for each seed.
- New base seed **20261037** disjoint from historical base 20261017,
  repeats 0–9; pinned C-derived reference backend commit
  `424a9fa2757914c3e4cfdd8f59a268b1aeb3197f`.
- Both function runners passed 58/58 finite/optimum-value benchmark preflights.
- GitHub Actions produced original CSV trials, a reproducibility manifest,
  bootstrap statistics, paired comparisons and a scientific SVG plot.

### Objective error — lower is better

| Function | ABC | EDBF | RE |
|:---|---:|---:|---:|
| F16 | **2,050.72** | 2,636.26 | 2,391.32 |
| F22 | **5,755.32** | 7,571.17 | 7,791.64 |

ABC attained the lowest measured mean error on **both** functions.

### Paired exact sign tests

A family of four prespecified two-sided paired sign tests was Holm-adjusted.

| Comparison | ABC wins/losses | Holm-adjusted p |
|:---|---:|---:|
| F16 ABC vs EDBF | 19/1 | **0.000160** |
| F16 ABC vs RE | 16/4 | **0.035454** |
| F22 ABC vs EDBF | 13/7 | 0.263176 |
| F22 ABC vs RE | 14/6 | 0.230637 |

**The F16 comparisons reached the p<0.05 threshold; the F22 sign tests did
not.** F22 has a highly dispersed ABC error distribution, so an advantage in
means, bootstrap intervals for mean errors, and a nonsignificant exact sign
test need not imply the same inferential claim. These analyses measure
different properties of the paired experiments.

The summary includes percentile-bootstrap 95% confidence intervals for
method means, alongside **10,000 paired-seed bootstrap resamples** of the
mean log1p error advantage.

## What changed relative to v0.9?

The 29-function, **3-seed** experiment had RE as the F16 mean-error leader
and EDBF as F22 leader. A separate historical **10-seed** trial already
favored ABC on F22. With **20 unused seeds**, ABC led on both F16 and F22,
demonstrating why small numbers of seeds make close algorithm rankings unstable.

**Do not pool** the separate 3-, 10- and 20-seed experimental cohorts
without explicit, statistically justified methodology.

## Scientific limits

The two functions were deliberately chosen because earlier rankings were
uncertain. These are targeted holdout experiments rather than a
publication-level all-29-function 20-seed evaluation. They do not validate
the original organizers' C executable nor reproduce the source paper's
100,000-function-evaluation budget.

Python 3.10, 3.11 and 3.12 tests, benchmark smoke tests, pipeline tests,
the wheel/sdist build and evidence regeneration must pass before release.
