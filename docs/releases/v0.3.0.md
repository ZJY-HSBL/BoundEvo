# BoundEvo v0.3.0

BoundEvo v0.3.0 turns the adaptive-boundary genetic optimizer into a reproducible experiment package.

## Highlights

- Adaptive-boundary, EDBF, and RE coefficient generators under one optimizer.
- CEC2017 experiment matrix for 29 functions.
- Source-aligned M=10..16 parent-count study on F1, F10, F20, and F30.
- One-million-proposal coefficient-efficiency experiment for M=1..20.
- Unified CLI: boundevo benchmark, boundevo sweep, boundevo efficiency, boundevo analyze.
- JSON experiment presets under configs/.
- Mean-rank and Win/Tie/Loss reports.
- Wilcoxon signed-rank tests with Holm correction and Friedman testing.
- Python 3.10, 3.11, and 3.12 CI, plus real CEC2017 smoke runs.

## Install

    git clone https://github.com/ZJY-HSBL/BoundEvo.git
    cd BoundEvo
    pip install -e ".[cec2017,analysis,plot]"

## Quick reproduction

    boundevo benchmark --config configs/cec2017.json
    boundevo sweep --config configs/parent_sweep.json
    boundevo efficiency --config configs/efficiency.json
    boundevo analyze --config configs/analysis.json

## Important interpretation notes

The extracted experiment-setting text states the population and recombination parameters but does not state benchmark dimensionality. The repository therefore treats dimension as an explicit experiment parameter; the supplied preset uses 10 only as a runnable default.

The adaptive-boundary flowchart contains an indexing ambiguity around the final coefficient. BoundEvo generates the first M-1 coefficients under adaptive bounds and computes the M-th coefficient from the sum constraint, preserving the stated M-dimensional coefficient vector.
