# BoundEvo v0.7.0 — Evidence-first README and 29-function screening

This release focuses on **real benchmark evidence in the repository homepage**.
All displayed numbers and figures are derived from committed experimental CSVs,
not fabricated or decorative illustrations.

## Dataset-backed README figures

Both [README](https://github.com/ZJY-HSBL/BoundEvo#measured-cec2017-results--30d)
and [README_CN](https://github.com/ZJY-HSBL/BoundEvo/blob/main/README_CN.md)
now contain automatically regenerated result tables and three original vector
figures:

- Normalized mean objective error against RE (D=30, 4 functions, 10 seeds);
- Runtime comparison for the same 120-trial independent-reference experiment;
- Per-function observed-mean winners across all 29 official CEC2017 functions.

Use `python scripts/update_readme_results.py` to regenerate the evidence.
`--check` verifies that committed figures and READMEs are current.
The [evidence workflow](https://github.com/ZJY-HSBL/BoundEvo/actions/workflows/readme-evidence.yml)
regenerates both READMEs automatically when configured experiment CSVs change.

## Real 29-function screening

A separate [261-trial screening dataset](https://github.com/ZJY-HSBL/BoundEvo/tree/main/docs/experiments/cec2017-screen-30d-2026-10-17)
now covers F1 and F3–F30 at D=30 with three paired initial seeds per method
and **1,200 function evaluations per trial**.

Lowest observed mean error:

| Method | Functions led |
|---|---:|
| ABC | **27 / 29** |
| EDBF | 0 / 29 |
| RE | 2 / 29 |

F20 and F22 were led by RE. The 29-function screening is **exploratory**:
three seeds are insufficient to establish per-function statistical significance
(the smallest possible two-sided sign-test p value is 0.25). These data must
not be pooled with the earlier 3,000-FE four-function experiment.

See [Chinese research analysis](https://github.com/ZJY-HSBL/BoundEvo/blob/main/docs/experiments/cec2017-screen-30d-2026-10-17/statistical_analysis_CN.md)
and [raw trials](https://github.com/ZJY-HSBL/BoundEvo/blob/main/docs/experiments/cec2017-screen-30d-2026-10-17/trials.csv).

## Reproducibility

- The benchmark implementation remains pinned to independent C-derived
  `cec2017-py` commit `424a9fa2757914c3e4cfdd8f59a268b1aeb3197f`.
- Both the 29-function screening and the older 120-trial experiment retain raw
  CSVs, metadata, preflight checks, and exact method/seed/evaluation settings.
- Figures, README results, and result tables are now linked to the same
  versioned data source through `configs/readme_results.json`.
- GitHub Actions checks Python 3.10–3.12, unit tests, the CEC2017 adapter,
  analysis/reporting, managed pipeline and packaging.

## Scientific caution

This release does **not** claim reproduction of the organizers' original C
binary or all of the source paper's full-budget experiments. Observed
mean-error leads and wall-clock speedups are specific to the tested functions,
budget, seeds, backend and runner.

The binary wheel and source distribution are attached to this Release.
