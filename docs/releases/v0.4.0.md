# BoundEvo v0.4.0

BoundEvo v0.4.0 adds managed experiment runs, sampled convergence history, and
self-contained research reporting on top of the v0.3 optimization and CEC2017
reproduction stack.

## Highlights

- Unique, non-overwriting Run IDs.
- Managed experiment bundles under `results/runs/<run-id>/`.
- New end-to-end `boundevo pipeline` command.
- Sampled convergence-history export for benchmark and parent-count experiments.
- Configurable `history_interval` to control logging volume.
- Standalone HTML reports with inline SVG graphics.
- Convergence curves averaged across repeated trials.
- Parent-count M-sensitivity curves.
- Coefficient-generation efficiency curves.
- Per-stage and root reproducibility manifests.
- Source revision, Python/runtime environment, and dependency versions captured automatically.
- Pipeline smoke testing in GitHub Actions.

## Install

~~~bash
git clone https://github.com/ZJY-HSBL/BoundEvo.git
cd BoundEvo
pip install -e ".[cec2017,analysis,plot]"
~~~

## Complete managed experiment

~~~bash
boundevo pipeline --config configs/pipeline.json
~~~

A run produces a structure similar to:

~~~text
results/runs/experiment-YYYYMMDDTHHMMSSZ-xxxxxxxx/
├── benchmark/
│   ├── trials.csv
│   ├── summary.csv
│   ├── history.csv
│   └── manifest.json
├── sweep/
│   ├── trials.csv
│   ├── summary.csv
│   ├── history.csv
│   ├── tables.md

├── efficiency/

│   └── manifest.json
├── report/
│   ├── report.html

└── manifest.json
~~~

## Reproducibility

Each stage records the resolved configuration, Run ID, BoundEvo version, Python
version, platform, NumPy/SciPy/opfunu/Matplotlib versions when installed, source
revision when available, and output locations.

## Reporting

The generated HTML report is self-contained. It embeds SVG charts directly and
does not require Python, Matplotlib, JavaScript, or a web server for viewing.

## Compatibility

Python 3.10, 3.11, and 3.12 are validated in CI. CEC2017 integration and the
managed pipeline are also exercised in clean GitHub Actions environments.
