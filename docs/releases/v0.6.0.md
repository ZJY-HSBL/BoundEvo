# BoundEvo v0.6.0 — Benchmark integrity and independent validation

This release focuses on evidence and reproducibility, not adding another
unvalidated optimization module.

## New benchmark backend

- Optional `backend="reference"` / `--backend reference` using the independent
  C-derived NumPy implementation at
  [tilleyd/cec2017-py](https://github.com/tilleyd/cec2017-py),
  pinned to commit `424a9fa2757914c3e4cfdd8f59a268b1aeb3197f`.
- Official CEC2017 function indices F1, F3..F30 with known bias Fk × 100.
- Reference backend selectable in Python, CLI benchmark, parent sweep, and
  managed pipeline. Original opfunu support retained for compatibility.
- Fail-fast check for objective values below reported global optimum.
- Benchmark and parent-sweep comparison methods now use **matched initial RNG
  seeds** within each function/repetition pair.
- Regression tests for benchmark dispatch, matching seeds and numerical guards.

## Actual numerical experiments

- Earlier exploratory pilot: 60 completed trials at D=10 using opfunu on
  F1, F3, F5, and F20 (results preserved without mixing backends).
- Independent reference-derived backend:
  - Preflight checks on 29 official functions at D=10 and D=30:
    **58/58 combinations passed sampled-point finite/optimum checks**.
  - **120 actual trials** at D=30, functions F1/F3/F10/F30, methods
    ABC/EDBF/RE, 10 matched seeds each, 3,000 evaluations per trial.
  - ABC reached lowest mean objective error on F1, F3, and F30.
  - **EDBF reached a slightly lower mean error on F10**; this demonstrates
    that ABC is not universally superior.
  - A paired exact sign test with Holm correction across eight contrasts
    reached p<0.05 for five contrasts; others were not significant.

## Installation

~~~bash
git clone https://github.com/ZJY-HSBL/BoundEvo.git
cd BoundEvo
pip install -e ".[analysis,plot]"
pip install "git+https://github.com/tilleyd/cec2017-py.git@424a9fa2757914c3e4cfdd8f59a268b1aeb3197f"
~~~

~~~bash
boundevo benchmark --config configs/cec2017.json --backend reference --dimension 30
~~~

## Scientific cautions

- The pinned reference-derived Python code is not the original official
  benchmark C binary; 58 sampled-point tests do not prove numerical
  equivalence at every point.
- The experiment covers four of the 29 official functions and uses only
  3,000 function evaluations, not the paper's larger evaluation budget.
- Shared seeds make initial populations identical, not later RNG streams.
- No empirical result from the opfunu backend has been pooled with the
  reference-derived backend.
- Performance numbers cannot be generalized to all benchmarks or hardware.

Versioned binary distributions and source archives are attached to this Release.
