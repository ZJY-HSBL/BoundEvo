# BoundEvo v0.8.0 — Real 10,000-evaluation research evidence

Version 0.8 focuses on checking whether the coefficient generator rankings
observed under smaller evaluation budgets persist when optimization runs longer.

## Real 30D experiments

- Official CEC2017 F10, F20, F22, F30, using an independent C-derived Python
  benchmark implementation pinned to
  `424a9fa2757914c3e4cfdd8f59a268b1aeb3197f`.
- ABC, EDBF, RE, ten paired initial seeds each: **120 completed real trials**.
- **10,000 function evaluations per trial**, including initial population.
- Validated exact evaluation budgets, full matched cohorts, finite errors and
  zero/seeded-point reference preflights (58/58).
- Raw CSV, summary statistics, paired tests, runner environment and Chinese
  statistical report committed to the repository.

| Function | ABC mean error | EDBF | RE | Lowest measured mean |
|---|---:|---:|---:|---|
| F10 | 7,470.23 | 7,501.86 | 7,661.92 | ABC |
| F20 | 785.20 | 1,129.80 | 1,049.46 | ABC |
| F22 | 5,717.56 | 7,651.46 | 7,300.07 | ABC |
| F30 | 188,044 | 61,932,211 | 5,511,292 | ABC |

ABC led in the observed mean on all four selected functions.
**The paired exact sign tests, adjusted together using Holm's method across
eight contrasts, support a 0.05-level difference only on F20 and F30**
against both baselines (four of eight contrasts, adjusted p=0.015625).
Results on F10 and F22 are **not statistically significant** after adjustment.

In earlier 1,200-FE three-seed screening RE had the lowest mean on F20 and
F22; in the earlier 3,000-FE ten-seed validation EDBF had a slightly lower
mean on F10. The new results show why evaluation budget affects rankings.

## Scientific limitations

Only four **purposively selected** functions were tested at 10,000 FEs.
No complete 29-function 10,000-FE experiment was performed, and these results
must not be pooled with earlier smaller-budget trials. Benchmarks are from
an independent reference-derived Python port, not the organizers' original C
binary. Ten repetitions and this function selection do not establish
universal algorithmic superiority.

CI covers Python 3.10–3.12, numerical smoke tests, packaging, experiment
history, report generation and the README evidence generator.
